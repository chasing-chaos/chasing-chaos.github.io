# Chasing Chaos

A small, static blog designed for GitHub Pages.

## Publish on GitHub Pages

1. Create a public GitHub repository named `chasing-chaos`.
2. Upload these files to the repository's `main` branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`.

The site will appear at `https://YOUR-USERNAME.github.io/chasing-chaos/`.

To make this your main profile website, name the repository `YOUR-USERNAME.github.io` instead.
